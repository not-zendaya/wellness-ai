# Intentional Living Assistant 🌿

A digital wellness assistant designed to help users reflect on unhealthy screen habits and receive mindful AI-powered wellness suggestions.

## Features

- AI-generated wellness suggestions
- Dark mode
- Daily reflection journaling
- Wellness streak tracker
- Responsive design

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Gemini API

## Running The Project

1. Clone the repository
2. Run `npm install`
3. Create a `.env` file
4. Add:

GEMINI_API_KEY=your_api_key_here

5. Run:

node server.js

6. Open:

http://localhost:3000
